# Hi, I'm Paul (socrtwo) 👋

I build practical, mostly client-side tools — file recovery utilities, genealogy
converters, Office add-ins, and progressive web apps that run on any platform.

🌐 **Browse everything in one place:** [socrtwo.github.io/socrtwo](https://socrtwo.github.io/socrtwo/) — a live, searchable gallery of all my projects.

## 🔧 Highlighted projects

### File repair & data recovery (S2 Recovery Tools)
- [Immortal-Zip](https://github.com/socrtwo/Immortal-Zip) — repair corrupt ZIP archives by scanning for local file headers, even when the central directory is gone.
- [Universal-File-Repair-Tool](https://github.com/socrtwo/Universal-File-Repair-Tool) — one tool, many corrupt file formats.
- [CorruptDOCXRepair](https://github.com/socrtwo/CorruptDOCXRepair), [wordrecovery-SF](https://github.com/socrtwo/wordrecovery-SF), [quickwordrecovr-SF](https://github.com/socrtwo/quickwordrecovr-SF) — recover damaged Word documents.
- [corruptexcelrec-SF](https://github.com/socrtwo/corruptexcelrec-SF), [excelrcvryaddin-SF](https://github.com/socrtwo/excelrcvryaddin-SF) — recover damaged Excel workbooks.
- [pptxrecovery-SF](https://github.com/socrtwo/pptxrecovery-SF), [oorecovery-SF](https://github.com/socrtwo/oorecovery-SF), [damageddocx2txt-SF](https://github.com/socrtwo/damageddocx2txt-SF), [datarecoverfree-SF](https://github.com/socrtwo/datarecoverfree-SF) — more recovery tools for PowerPoint, OpenOffice, and general data.

### Genealogy
- [excel2ged](https://github.com/socrtwo/excel2ged) / [excel2ged-SF](https://github.com/socrtwo/excel2ged-SF) — turn an Excel spreadsheet of family data into a valid GEDCOM 5.5.1 file.
- [ged2wiki-SF](https://github.com/socrtwo/ged2wiki-SF) — convert GEDCOM files into wiki pages, fully client-side.
- [genealogyoflife-SF](https://github.com/socrtwo/genealogyoflife-SF), [catalog-of-life-SF](https://github.com/socrtwo/catalog-of-life-SF) — the tree of life, treated as a family tree.

### Microsoft Office tooling
- [qat-exposer](https://github.com/socrtwo/qat-exposer) — SuperQAT: search and launch all 2,199 Office 365 commands from one add-in.
- [savvyoffice-SF](https://github.com/socrtwo/savvyoffice-SF), [saveofficedata-SF](https://github.com/socrtwo/saveofficedata-SF), [shiftf3-SF](https://github.com/socrtwo/shiftf3-SF) — Office productivity utilities.

### Networking & misc
- [VPN-Follower](https://github.com/socrtwo/VPN-Follower) — CLI + PWA that reports the network, geolocation, and VPN/proxy/Tor signals behind an IP, host, or URL.
- [sf-to-github](https://github.com/socrtwo/sf-to-github) — migrate SourceForge projects to GitHub (how the `-SF` repos got here).
- [the-best-of-brock-cookbook](https://github.com/socrtwo/the-best-of-brock-cookbook) — an interactive cookbook PWA with timers, recipe scaling, and shopping lists.
